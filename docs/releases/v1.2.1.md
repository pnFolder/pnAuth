# v1.2.1 — Исправлена конфигурация маршрутизации

Версия исправляет сохранение пользовательского `config.yml` и делает тип каждого серверного маршрута явным.

## Исправлено
- Актуальный `config.yml` больше не перезаписывается при запуске только из-за отсутствующих необязательных параметров.
- Пользовательские значения и структура YAML сохраняются без автоматической подстановки дефолтов на диск.
- Автоматическая запись конфигурации выполняется только при реальной миграции старой схемы; резервная копия `.bak` для миграций сохранена.
- В `servers.auth` и `servers.backend` у маршрута появился явный `type`: `SERVER` или `LIMBO`.
- `LIMBO` разрешён только для `servers.auth`; backend-маршруты всегда используют `SERVER`.
- pnAuth больше не определяет тип явно настроенного маршрута только по совпадению имени с `limbo.server-name`.
- Один сервер нельзя одновременно объявить в `servers.auth` и `servers.backend`; вместо конфликта online выводится понятная ошибка о пересечении ролей.
- Старые конфиги без `type` остаются совместимыми: для них сохраняется прежнее распознавание встроенного Limbo по `limbo.server-name`.

## Пример
```yaml
servers:
  auth:
    - server: auth
      online: 100
      type: LIMBO
  backend:
    - server: lobby
      online: 200
      type: SERVER
```
