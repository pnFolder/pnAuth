# v1.2.1 — Исправлено сохранение конфигурации

Версия предотвращает откат пользовательских настроек при запуске pnAuth.

## Исправлено
- Актуальный `config.yml` больше не перезаписывается при запуске только из-за отсутствующих необязательных параметров.
- Пользовательские значения и структура YAML сохраняются без автоматической подстановки дефолтов на диск.
- Автоматическая запись конфигурации выполняется только при реальной миграции старой схемы; резервная копия `.bak` для миграций сохранена.

## Совместимость
- Java 17
- Единая сборка pnAuth для BungeeCord, Velocity и Paper
