# v1.2.2 — Исправлена загрузка конфигурации

Версия делает загрузку `config.yml` безопасной и предсказуемой при запуске и перезагрузке pnAuth.

## Улучшено
- Упрощена настройка маршрутов: поле `type: SERVER/LIMBO` больше не требуется.
- Включённый Limbo автоматически определяется по совпадению маршрута из `servers.auth` с `limbo.server-name`.
- Старые схемы и прежнее поле `type` продолжают поддерживаться без изменения файла на диске.

## Исправлено
- pnAuth больше не перезаписывает, не форматирует и не дополняет существующий `config.yml` при запуске или `/auth reload`.
- Миграции старых схем выполняются только в памяти и сохраняют пользовательские значения, комментарии и порядок YAML.
- Новый `config.yml` создаётся атомарно, а ошибочный YAML отклоняется без повреждения исходного файла и без оставшихся временных файлов.

## Совместимость
- Java 17 или новее.
- Единая универсальная сборка pnAuth для BungeeCord, Velocity и Paper.
- Отдельная универсальная сборка pnAuth Hub.
